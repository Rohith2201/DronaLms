# Drona LMS Frontend

Angular frontend for Drona LMS.

## Run locally

```bash
cd frontend
npm install
npm start
```

App URL: `http://localhost:4200`

## Configuration

Environment file: `src/environments/environment.ts`

Default API base:
- `apiUrl: /api/v1`
